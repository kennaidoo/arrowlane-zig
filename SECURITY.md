# Security policy

## Supported versions

The latest commit on `main` is the supported version. Older commits are not
supported.

## Reporting a vulnerability

Report privately through GitHub. Open the repository's Security tab and choose
Report a vulnerability. Do not open a public issue.

Include the affected commit, the steps to reproduce, and the impact.

You get an acknowledgement within 30 days. A fix or a documented decision
follows within 120 days. These are best-effort targets, not a service-level
agreement.

## Scope

This repository is a demonstration. It holds no production data and uses no
credentials. Do not send real credentials, customer data or private keys in a
report. A leaked real credential should use the same private route.
